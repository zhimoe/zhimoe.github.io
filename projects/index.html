项目

最近在写的一些开源项目

这里收录我最近在维护的几个开源项目，完整的列表见 GitHub @zhimoe。

Nimi

用 Nim 重实现的桌面应用框架：系统 WebView、类型化 IPC 与自绘原生 UI，目标是单二进制、低开销的跨平台桌面开发。

Nim · WebView · macOS 官网GitHub

MyGo Work

面向本地文件与项目的 Agent 工作台。桌面端基于 MyGo，Go 宿主管理本地工作区、引擎进程与模型交互。

MyGo · Agent · Desktop 下载GitHub

EnvMan

原生 Windows 环境变量管理器。使用 Go 与 MyGo native UI 绘制，不依赖 WebView，支持提权写入、自动备份与多值变量编辑。

Go · Windows · MyGo GitHub

mdict-rs

基于 Rust + Actix 的在线 MDict 词典，读取 MDX 格式词典文件，目前支持 MDX 2.0。

Rust · Actix · MDX GitHub

PicX

轻量的 GitHub 图床：拖入图片自动转 WebP 并上传到自己的仓库，返回 jsDelivr 链接与 Markdown，部署在 Cloudflare Workers。

TypeScript · SolidJS · Cloudflare 在线体验GitHub

Programming Fonts

自用的编程字体改造合集：中英混排、等宽终端适配、Powerline 与 Nerd Fonts 补丁，收录 Source Code Pro、Fira Code 等改版。

Fonts · Python · Typography GitHub
